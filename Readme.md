# Drag-n-Drop Dock

Реализация перетаскиваемых (drag-n-drop) док-панелей (`QDockWidget`) для Qt. Возможно создание кастомных доков, которые можно перетаскивать не только внутри одного главного окна, но и между разными окнами приложения, с автоматическим объединением во вкладки (tabify) или созданием новых окон.

## Стек 

- **Язык**: C++ (совместимо с C++11/14/17)
- **Фреймворк**: Qt (Qt Widgets,  Qt 5.12+)
- **Система сборки**: QMake
